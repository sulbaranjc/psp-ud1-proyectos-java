# PSP · UD1 · Proyectos Java ejecutables

Retos de consola en Java 21 para la **UD1: Programación concurrente, multiproceso y paralelismo** del módulo Programación de Servicios y Procesos (0490, DAM · ILERNA).

## Retos

| Reto | Paquete | Qué demuestra |
|---|---|---|
| [Reto01 · Identifica tu proceso](Reto01_Identifica_Tu_Proceso/) | `es.ilerna.psp.ud1.reto01` | Un programa al ejecutarse se convierte en un proceso con PID y PPID propios. |

## Requisitos

- JDK 21 (LTS) con `javac` y `java` en el PATH.
- Linux/macOS: `./ejecutar.sh` · Windows: `ejecutar.bat` (dentro de la carpeta de cada reto).

## Abrir en IntelliJ IDEA

Abre esta carpeta raíz como proyecto. Si IntelliJ pide un SDK, selecciona cualquier JDK 21.
